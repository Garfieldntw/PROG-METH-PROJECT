# 🥗 Salad Smash Java Game

A 2-player offline arcade game inspired by Bomb It!, developed using Java and JavaFX as part of a Programming Methodology course.

---

## 🎮 Overview
Salad Smash is a simple competitive game where two players interact in a shared environment.  
The project focuses on applying object-oriented programming (OOP) concepts and building an interactive graphical user interface.

---

## ✨ Features
- 2-player offline gameplay  
- Object-oriented design (OOP)  
- Interactive GUI built with JavaFX  
- Basic player movement and in-game interactions  

---

## 🛠️ Technologies Used
- Java  
- JavaFX
